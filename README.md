Study materials, seminars and projects for **CIN0150 - Compiladores** (Compilers), class T01, 2026.2, at the [Centro de Informática, UFPE](https://portal.cin.ufpe.br/).

## Running the examples

The seminar examples need a JDK (17 or newer):

```bash
cd seminario-featherweight-java/exemplos
javac -d /tmp/fj src/*.java
java -cp /tmp/fj Main
```

## Viewing the slides

Open `seminario-featherweight-java/apresentacao/index.html` in a browser. Arrow keys, Space or PageUp/PageDown navigate; F toggles fullscreen.
